# Focus Tracker

Мобильный MVP для учёта задач, Pomodoro и анализа отвлечений. Фронтенд — чистые HTML/CSS/JavaScript, данные — только в Google Sheets через Google Apps Script.

## Быстрый запуск

1. Создайте пустую Google Sheet и скопируйте её ID из URL (часть между `/d/` и `/edit`).
2. В таблице откройте **Расширения → Apps Script**, замените содержимое редактора кодом из `google-apps-script.gs` и укажите ID в `SPREADSHEET_ID`.
3. В Apps Script нажмите **Развернуть → Новое развертывание → Веб-приложение**. Выберите: *Выполнять от имени: я*, *Кто имеет доступ: все*. Разрешите запрошенные доступы и скопируйте URL, оканчивающийся на `/exec`.
4. Откройте `index.html` через GitHub Pages. Нажмите ⚙ и вставьте URL Web App. При первом запросе автоматически будут созданы листы и категории.

## Публикация на GitHub Pages

1. Создайте GitHub-репозиторий и загрузите пять файлов этого проекта в его корень.
2. В репозитории перейдите в **Settings → Pages**.
3. В *Build and deployment* выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем **Save**.
4. Через несколько минут откройте опубликованный адрес `https://<ваш-логин>.github.io/<репозиторий>/` на iPhone в Safari.

## Листы Google Sheets

Приложение создаёт их автоматически: `categories`, `tasks`, `sessions`, `distractions`, `settings`. Не меняйте порядок колонок в этих листах. Категории можно переименовывать; `Deep Work` оставьте с этим точным названием, чтобы Focus Rate рассчитывался правильно.

## Поведение таймера

- Работа: 25 минут; короткий отдых: 5; длинный: 15 после каждого четвёртого рабочего цикла.
- Пауза требует указать причину и создаёт событие отвлечения. Resume его закрывает.
- Факт задачи пересчитывается из завершённых рабочих сессий. Так как факт фиксируется в полных минутах, очень короткие тестовые сессии могут дать 0 минут.

## Повторное развертывание Apps Script

После изменения `google-apps-script.gs` выберите **Развернуть → Управление развертываниями → Изменить** и создайте новую версию. URL `/exec` обычно останется тем же.

## Важно

URL API сохраняется только как настройка браузера (`localStorage`). Никакие задачи, сессии или отвлечения локально не хранятся. Для личного использования настройте доступ к Web App так, чтобы он открывался только вам, если ваш Google Workspace позволяет этот вариант; для публичного GitHub Pages доступ «все» нужен, чтобы Safari мог вызвать API без авторизации.
